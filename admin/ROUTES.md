# خريطة الأزرار والمسارات (Button Map)

✅ = شغّال ومربوط · ⬜ = زر شكلي (التصميم ما فيه شاشة له) · 🔸 = افتراض مني، بحاجة لتأكيدك

## المسارات

| المسار | الشاشة | المصدر |
|---|---|---|
| `/login` | تسجيل دخول مدير النظام | تصميم |
| `/user-login` | تسجيل دخول الموظف (نظام إدارة المشتريات والعقود الذكي) | تصميم |
| `/forgot-password` | استعادة كلمة المرور | تصميم |
| `/reset-password` | إنشاء كلمة مرور جديدة (من رابط الاستعادة) | تصميم |
| `/first-login-password` | إنشاء كلمة مرور جديدة (الجلسة الأولى) | تصميم |
| `/` | لوحة التحكم والمتابعة | تصميم |
| `/users` | إدارة المستخدمين (القائمة) | تصميم |
| `/users/new` | إضافة مستخدم جديد (4 خطوات) | تصميم |
| `/users/:id` | تفاصيل المستخدم | تصميم |
| `/users/:id/permissions` | إدارة الصلاحيات | ⬜ صفحة فاضية بالهيكل فقط |
| `/users/:id/edit` | تعديل المستخدم | ⬜ صفحة فاضية بالهيكل فقط |
| `/roles` | الأدوار والصلاحيات (القائمة + لوحة المصفوفة) | تصميم |
| `/roles/new` | إضافة دور جديد (+ نافذة إضافة صلاحية) | تصميم |
| `/roles/:key/edit` | تعديل الدور | ⬜ صفحة فاضية بالهيكل فقط |
| `/vendors` | الموردون (القائمة + فلاتر + جدول) | تصميم |
| `/vendors/new` | إضافة مورد جديد | تصميم |
| `/vendors/:id` | تفاصيل المورد (نشط / معلّق + نافذتا التعطيل وإعادة التفعيل) | تصميم |
| `/vendors/:id/edit` | تعديل بيانات المورد | تصميم |
| `/master-data` `/settings` | القوائم الجانبية الأخرى | ⬜ صفحات فاضية بالهيكل فقط |
| `/audit-log` | سجل التدقيق (Audit Log) | ⬜ صفحة فاضية بالهيكل فقط |
| `/support` `/privacy` `/cyber-compliance` | روابط الفوتر | ⬜ صفحات فاضية بالهيكل فقط |

## 1) شاشات الدخول

| العنصر | الوجهة / السلوك |
|---|---|
| تسجيل الدخول (`/login`، `/user-login`) | أي قيمتين غير فاضيتين ← `/` ✅ . الحقل الفاضي يتلوّن بالأحمر 🔸 |
| تذكرني | تبديل الـ checkbox ✅ |
| هل نسيت كلمة المرور؟ | `/forgot-password` ✅ |
| ارسال رابط الإستعادة | حقل إلزامي، ثم تظهر الملاحظة الأمنية (الحالة الثانية بالتصميم) ✅ |
| العودة لتسجيل الدخول | `/login` ✅ |
| تحديث و حفظ كلمة المرور | يتفعّل لما تتحقق الشروط الأربعة والتطابق ← `/login` ✅ 🔸 |
| حفظ والمتابعة إلى المنظومة | نفس الشروط + كلمة المؤقتة ← `/` ✅ 🔸 |
| تسجيل الخروج والعودة لاحقا | `/login` ✅ |
| شروط الأمان (8 خانات، حرف كبير، رقم، رمز) | تنعلّم تلقائياً أثناء الكتابة ✅ |
| الامتثال السيبراني / سياسة الخصوصية / الدعم الفني | `/cyber-compliance` `/privacy` `/support` ⬜ |
| عربية / English | ✅ يبدّل اللغة والاتجاه (ترجمة كاملة) |

## 2) الهيكل المشترك (الشريط الجانبي والهيدر)

| العنصر | الوجهة |
|---|---|
| الشعار | `/` ✅ |
| الرئيسية / المستخدمون | `/` و `/users` ✅ |
| الأدوار والصلاحيات / الموردين / البيانات الأساسية / الإعدادات | `/roles` `/vendors` ✅ و `/master-data` `/settings` ⬜ |
| مسار التنقل (breadcrumb) | `/` و `/users` ✅ |
| حقل البحث العلوي | Enter ← `/users` 🔸 |
| الجرس، سهم البطاقة السفلية | ⬜ شكلي |  
| زر اللغة (عربية / English) | ✅ قائمة تبدّل اللغة والاتجاه |

## 7) الأدوار والصلاحيات `/roles`

| العنصر | السلوك |
|---|---|
| إضافة دور جديد | `/roles/new` ✅ |
| البحث / الحالة / نوع الدور | فلترة القائمة فوراً، وعدّاد «عرض N من أصل M» يتحدث ✅ |
| تحديث (فوق القائمة) | يرجّع الفلاتر للوضع الافتراضي (الحالة: نشط، النوع: الكل) ✅ 🔸 |
| بطاقة الدور (ضغطة على البطاقة) | تحديدها وفتح لوحة المصفوفة على اليسار ✅ |
| عرض المستخدمين | `/users` ✅ 🔸 (ما فيه تصفية حسب الدور بالتصميم) |
| تعديل الدور | `/roles/:key/edit` ⬜ |
| ⋮ على البطاقة | قائمة فيها نفس الزرين: عرض المستخدمين / تعديل الدور 🔸 |
| لوحة المصفوفة: مربع الصلاحية | تفعيل/إلغاء، وعدّاد الوحدة والإجمالي يتحدثوا ✅ |
| تحديد الكل (باللوحة) | يفعّل الكل، وإذا كلها مفعلة يلغيها ✅ 🔸 |
| أيقونة التحديث (باللوحة) | ترجيع آخر حالة محفوظة ✅ |
| إلغاء التغييرات | ترجيع آخر حالة محفوظة ✅ |
| حفظ مصفوفة الصلاحيات | يحفظ بالذاكرة ويحدّث «N صلاحيات معتمدة» بالبطاقة ✅ |
